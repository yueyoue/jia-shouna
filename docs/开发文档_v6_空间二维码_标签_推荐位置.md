## 1. 功能总览

### 1.1 衣帽间套装系统

将多件服装/鞋帽组合为「套装」（如通勤穿搭、运动套装），按场景快速查看搭配。

| 功能 | 说明 |
|------|------|
| 创建套装 | 从已有物品中选择组合，指定季节/场合 |
| 浏览套装 | 按季节/场合筛选，大封面图网格展示 |
| 编辑/删除 | 修改名称、季节、场合、关联物品 |
| 录入时关联 | 新增物品时可直接创建新套装或加入已有套装 |
| AI 自动识别 | 拍照识别物品颜色和季节，自动填入 |

### 1.2 物品借出功能

将物品借给他人，支持设置归还提醒。

| 功能 | 说明 |
|------|------|
| 借出 | 指定借出对象、数量、归还提醒天数（7/15/30/60天） |
| 归还 | 一键归还，自动恢复库存 |
| 提醒 | 到期自动推送到提醒页面「借出中」选项卡 |
| 记录 | 完整借出/归还记录，显示借出天数 |

### 1.3 物品流转日志

记录物品全生命周期操作，物品详情页底部展示。

| 操作类型 | 说明 |
|----------|------|
| `create` | 物品录入 |
| `edit` | 编辑物品信息 |
| `borrow` | 领取物品 |
| `lend` | 借出物品（含借出对象） |
| `return` | 归还物品 |

### 1.4 文件档案模块

证件、合同、票据等文件的数字化存档，记录物理存放位置。

| 功能 | 说明 |
|------|------|
| 分类管理 | 证件/合同/票据/保单/房产/车辆/教育/医疗/其他 |
| 元数据 | 证件号码、签发机构、签发日期、到期日期 |
| 照片 | 拍照扫描或相册上传文件照片 |
| 存放位置 | 空间选择器（与物品录入一致），记录物理位置 |
| 到期提醒 | 提前30天自动创建提醒 |
| 隐私控制 | 私密（仅自己）/ 共享（家庭成员可见） |

### 1.5 底部导航调整

| Tab | 顺序 | 说明 |
|-----|------|------|
| 首页 | 1 | HomeFragment |
| 空间 | 2 | SpacesFragment |

### 1.6 Web 端备份增强

- JSON 导出新增：outfit、outfit_item、goods_log、document、document_image
- CSV 导出新增字段：颜色、季节、尺码、材质、鞋码
- 统计面板新增：套装数量、借出中数量、文件档案数量
- 恢复指南包含全部4个迁移脚本

### 1.7 空间二维码系统（v1.7 新增）

为每个空间生成唯一6位编码，生成二维码，扫码可查看该空间所有物品。

| 功能 | 说明 |
|------|------|
| 空间编码 | 6位大写字母+数字（排除易混淆字符 O/0/I/1/L），创建空间时自动生成 |
| 二维码生成 | 编码格式 `JSN:SPACE:{code}`，使用 ZXing 生成 |
| 保存打印 | 二维码卡片含空间名+编码+二维码，可保存到相册或批量导出打印 |
| 扫码导航 | APP 扫描空间二维码自动跳转空间详情页 |
| WEB端同步 | 空间详情显示编码，支持单个/批量二维码导出和打印 |

### 1.8 自动标签生成（v1.7 新增）

AI识别和条码扫描时自动生成标签，减少手动操作。

| 功能 | 说明 |
|------|------|
| 关键词提取 | 从物品名称提取关键词匹配标签（12组关键词映射：调料/药/饮料/零食/数据线/电池/洗涤/纸巾/文具/工具/化妆品/护肤） |
| 分类匹配 | 根据AI识别的分类自动生成对应标签 |
| 标签库匹配 | 与已有标签库模糊匹配，复用已有标签 |
| 条码复用 | 扫码识别到商品后，自动根据商品名生成标签 |
| WEB标签管理 | 独立标签管理页面：创建/编辑/删除/查看物品 |

### 1.9 推荐存放位置（v1.7 新增）

录入物品时根据标签和相似物品推荐存放位置。

| 功能 | 说明 |
|------|------|
| 标签推荐 | 查询同类标签物品的存放位置，推荐最常用空间 |
| 名称推荐 | 根据物品名称模糊匹配已有物品的存放位置 |
| 阈值控制 | 同类物品≥2件才显示推荐，新账号不推荐 |
| 一键使用 | 点击「使用」按钮自动填入存放位置 |

### 1.10 空间无限层级嵌套（v1.7 新增）

空间页面支持任意层级嵌套显示，不再限制为两层。

| 功能 | 说明 |
|------|------|
| 递归渲染 | SpacesFragment 递归渲染所有层级空间 |
| 展开折叠 | 每个有子级的空间可展开/折叠，状态持久化 |
| 逐级缩进 | 每层缩进 24dp，视觉层级清晰 |

## 2. 数据库设计

### 2.1 outfit 表（套装）

```sql
CREATE TABLE IF NOT EXISTS `outfit` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
    `house_id` INT UNSIGNED NOT NULL,
    `creator_id` INT UNSIGNED NOT NULL,
    `name` VARCHAR(100) NOT NULL,
    `season` VARCHAR(30) DEFAULT '',
    `occasion` VARCHAR(50) DEFAULT '',
    `cover_image` VARCHAR(500) DEFAULT '',
    `note` TEXT DEFAULT NULL,
    `status` TINYINT NOT NULL DEFAULT 1,
    `created_at` INT UNSIGNED NOT NULL,
    `updated_at` INT UNSIGNED NOT NULL,
    PRIMARY KEY (`id`),
    KEY `idx_house` (`house_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.2 outfit_item 表（套装-物品关联）

```sql
CREATE TABLE IF NOT EXISTS `outfit_item` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
    `outfit_id` INT UNSIGNED NOT NULL,
    `goods_id` INT UNSIGNED NOT NULL,
    `slot` VARCHAR(20) DEFAULT '',
    `sort_order` INT DEFAULT 0,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_outfit_goods` (`outfit_id`, `goods_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.3 goods 表新增字段

```sql
ALTER TABLE goods ADD COLUMN color VARCHAR(30) DEFAULT '';

ALTER TABLE goods ADD COLUMN size VARCHAR(20) DEFAULT '';
ALTER TABLE goods ADD COLUMN material VARCHAR(50) DEFAULT '';
ALTER TABLE goods ADD COLUMN shoe_size VARCHAR(10) DEFAULT '';
```

### 2.4 goods_borrow 表新增字段

```sql
ALTER TABLE goods_borrow ADD COLUMN lend_to VARCHAR(100) DEFAULT '' COMMENT '借出对象';
ALTER TABLE goods_borrow ADD COLUMN remind_at INT UNSIGNED DEFAULT NULL COMMENT '归还提醒时间戳';
```

### 2.5 goods_log 表（流转日志）

```sql
CREATE TABLE IF NOT EXISTS `goods_log` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
    `goods_id` INT UNSIGNED NOT NULL,
    `user_id` INT UNSIGNED NOT NULL,
    `action` VARCHAR(30) NOT NULL COMMENT 'create/edit/borrow/lend/return/import',
    `detail` VARCHAR(500) DEFAULT '',
    `extra` TEXT DEFAULT NULL COMMENT '扩展JSON',
    `created_at` INT UNSIGNED NOT NULL,
    PRIMARY KEY (`id`),
    KEY `idx_goods` (`goods_id`),
    KEY `idx_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.6 document 表（文件档案）

```sql
CREATE TABLE IF NOT EXISTS `document` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
    `house_id` INT UNSIGNED NOT NULL,
    `creator_id` INT UNSIGNED NOT NULL,
    `name` VARCHAR(200) NOT NULL,
    `category` VARCHAR(30) NOT NULL DEFAULT '其他',
    `doc_no` VARCHAR(100) DEFAULT '',
    `issuer` VARCHAR(100) DEFAULT '',
    `issue_date` DATE DEFAULT NULL,
    `expiry_date` DATE DEFAULT NULL,
    `storage_location` VARCHAR(200) DEFAULT '',
    `space_id` INT UNSIGNED DEFAULT NULL,
    `note` TEXT DEFAULT NULL,
    `is_private` TINYINT NOT NULL DEFAULT 1,
    `status` TINYINT NOT NULL DEFAULT 1,
    `created_at` INT UNSIGNED NOT NULL,
    `updated_at` INT UNSIGNED NOT NULL,
    PRIMARY KEY (`id`),
    KEY `idx_house` (`house_id`),
    KEY `idx_category` (`category`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.7 document_image 表

```sql
CREATE TABLE IF NOT EXISTS `document_image` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
    `document_id` INT UNSIGNED NOT NULL,
    `image_path` VARCHAR(500) NOT NULL,
    `sort_order` INT NOT NULL DEFAULT 0,
    `created_at` INT UNSIGNED NOT NULL,
    PRIMARY KEY (`id`),
    KEY `idx_doc` (`document_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.8 ER 关系图

```
house 1──N outfit 1──N outfit_item N──1 goods
                                      N──1 goods_image
                                      N──1 goods_log
                                      N──1 goods_borrow

house 1──N document 1──N document_image

goods_borrow:
  - borrow: user_id → 领用人, lend_to 为空
  - lend:   user_id → 操作人, lend_to → 借出对象
```

### 3.1 套装 API — `backend/api/outfit.php`

| 接口 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `?action=create` | POST | house_id, name, season?, occasion?, note?, items[] | 创建套装 |
| `?action=list` | GET | house_id, season?, occasion?, keyword?, page? | 套装列表 |
| `?action=detail` | GET | id | 套装详情 |
| `?action=update` | POST | id, name?, season?, occasion?, note?, items[]? | 更新套装 |
| `?action=delete` | POST | id | 软删除 |

### 3.2 借出 API — `backend/api/goods.php`

| 接口 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `?action=borrow` | POST | goods_id, quantity, note? | 领用物品 |
| `?action=lend` | POST | goods_id, quantity, lend_to, remind_days?, note? | 借出物品 |
| `?action=return` | POST | borrow_id | 归还（领用/借出通用） |
| `?action=borrowList` | GET | house_id?, goods_id? | 列出借出中记录 |
| `?action=flowLog` | GET | goods_id | 物品流转日志 |

### 3.3 文件档案 API — `backend/api/document.php`

| 接口 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `?action=list` | GET | house_id, category?, keyword?, expiring?, page? | 列表 |
| `?action=detail` | GET | id | 详情（含图片） |
| `?action=create` | POST | house_id, name, category, ... | 创建 |
| `?action=update` | POST | id, ... | 更新 |
| `?action=delete` | POST | id | 软删除 |
| `?action=stats` | GET | house_id | 统计 |

### 3.4 空间 API 扩展 — `backend/api/space.php`（v1.7 新增）

| 接口 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `?action=generate_code` | GET | id | 生成/获取空间编码 |
| `?action=lookup_code` | GET | code | 根据编码查找空间（扫码用） |
| `?action=recommend_location` | GET | house_id, tags?, name? | 推荐存放位置 |

**generate_code 返回：**
```json
{"code": 0, "data": {"space_code": "A3K7NP", "space_name": "书桌"}}
```

**lookup_code 返回：**
```json
{"code": 0, "data": {"space": {"id": 5, "name": "书桌", "house_id": 1, "space_code": "A3K7NP", ...}}}
```

**recommend_location 返回：**
```json
{
    "code": 0,
    "data": {
        "recommendations": [
            {"space_id": 3, "space_name": "厨房", "space_code": "B2M5HT", "count": 5, "reason": "同类「调料」物品存放处"}
        ]
    }
}
```

**推荐逻辑：**
1. 根据标签查询同类物品的存放位置，按数量排序
2. 根据物品名称模糊匹配已有物品的存放位置
3. 合并结果，同类物品≥2件才返回推荐

### 3.5 提醒 API — `backend/api/reminder.php`

`?action=list` 新增自动生成的借出到期提醒。

### 3.6 图片上传 — `backend/api/upload.php`

## 7. 已修复的问题

### 7.1 套装关联丢失

**问题**：物品通过拍照/相册录入时，选择新建套装后保存，物品未加入套装。

**修复**：在 `createGoodsWithImages()` 的 onSuccess 中加入 `pendingOutfitId` 检查。

### 7.2 AI 识别 2MB 限制

**问题**：从相册选取照片进行 AI 识别时提示「图片大小不能超过 2MB」。

**修复**：相册路径统一压缩策略（resizeBitmap(1600) + 80% JPEG）。

### 7.3 照片方向错误

**问题**：手机拍照后照片横着显示。

**修复**：新增 `fixPhotoOrientation()` 方法，读取 EXIF orientation tag 修正。

### 7.4 底部导航崩溃

**问题**：添加「提醒」Tab 后 APP 启动崩溃。

**修复**：移除「扫码」Tab，保留 5 项。提醒图标改为自定义 drawable。

### 7.5 编译报错：GradientDrawable 找不到（v1.7 修复）

**问题**：`AddDocumentActivity.java` 使用 `GradientDrawable` 但缺少 import。

**修复**：添加 `import android.graphics.drawable.GradientDrawable;`

### 7.6 相册打开文件管理器（v1.7 修复）

**问题**：APP 中所有「相册选择」按钮打开的是手机文件管理器而非相册。

**原因**：使用 `ACTION_PICK` 在部分设备上打开文件管理器。

**修复**：统一改为 `ACTION_GET_CONTENT` + `CATEGORY_OPENABLE` + `Intent.createChooser`。

### 7.7 衣帽间筛选选项显示不全（v1.7 修复）

**问题**：新建套装页面的三个筛选 Spinner 只显示一个「全」字。

**原因**：Spinner 默认文字大小 + 等分宽度不够。

**修复**：为筛选 Spinner 创建紧凑适配器（11sp 字体+居中+减少 padding）。

### 7.8 空间只显示两层（v1.7 修复）

**问题**：创建三级空间（如 书房→书桌→药盒）后，药盒不显示。

**原因**：`SpacesFragment.renderSpaces()` 只渲染两层（顶级+直接子级）。

**修复**：新增 `createSubItemRecursive()` 方法，递归渲染任意层级。

### 7.9 文件档案加载失败（v1.7 修复）

**问题**：APP 文件档案页面显示「加载失败」。

**原因**：后端 `document.php` 未捕获 PHP 异常，导致 HTTP 500 空响应。

**修复**：`document.php` 整体包裹 try-catch，异常时返回 JSON 错误信息。
